# 101 Bistro Recipe Wiki

This repository contains a static recipe wiki for 101 Bistro.

The site is designed to use English as the primary working language, with Hungarian source text and Chinese translation notes available for review.

## Files

- `index.html` is the main page.
- `app.js` contains the browser app logic.
- `app-data.js` contains imported recipe data.
- `styles.css` contains the visual styling.
- `.github/workflows/pages.yml` deploys the site to GitHub Pages.

## Notes

The imported recipe data was extracted from a PDF and should be reviewed by the kitchen before operational use.
